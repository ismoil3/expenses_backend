# Amiri — трекер расходов в Telegram · backend

Пишете боту `кофе 350` — расход сохранён. Категорию определяет AI.
Аккаунт — это ваш Telegram: ни регистрации, ни паролей.

**Бот:** [@amiri_expenses_bot](https://t.me/amiri_expenses_bot)
**Панель:** _(добавится после деплоя)_
**Репозиторий панели:** [expenses_frontend](https://github.com/ismoil3/expenses_frontend)

Здесь — бот, REST API и база. Веб-панель лежит в отдельном репозитории и
ходит сюда по HTTP; общего кода между ними нет.

---

## Что умеет

**Ввод**

- Расход одним сообщением: `кофе 350`, `350 кофе`, `такси 900 работа`
- Несколько сразу: `кофе 350, такси 900, хлеб 20` → три записи и кнопка «Отменить всё»
- Свободный текст: «потратил триста пятьдесят на кофе», «нон сад сомонӣ» — сумму достаёт AI
- Фото чека: бот читает итоговую сумму. Подпись к фото становится описанием
- Три валюты: `5$ подписка`, `500р курс`, `350с хлеб`

**Категории**

- Определяются сами: явный `#тег` → память пользователя → трёхъязычный словарь → OpenAI
- Если ничего не подошло — AI предлагает новую категорию, пользователь подтверждает кнопкой
- Бот учится: поправили категорию один раз — дальше это слово распознаётся мгновенно

**Отчёты и контроль**

- `/today`, `/week`, `/month` — по категориям и по дням, диаграммой прямо в чате
- Лимиты по категориям на месяц: предупреждение на 80% и при превышении
- Правка и удаление, восстановление после удаления
- Выгрузка CSV
- Три языка интерфейса: таджикский, русский, английский

## Требования

- Python 3.12+
- PostgreSQL 14+
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ [OpenAI](https://platform.openai.com) (без него бот работает, но
  категории определяются только словарём)

## Запуск

**1. Настройки**

```bash
cd backend
cp .env.example .env
```

В `.env` впишите как минимум:

```env
BOT_TOKEN=123456789:AA...
OPENAI_API_KEY=sk-...
DATABASE_URL=postgresql+asyncpg://postgres:пароль@localhost:5432/amiri
JWT_SECRET=<64 символа>
```

Секрет сессии:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

**2. База**

```bash
psql -U postgres -c "CREATE DATABASE amiri;"
```

**3. Зависимости**

```bash
py -m venv .venv

source .venv/Scripts/activate      # Git Bash
# .\.venv\Scripts\Activate.ps1     # PowerShell
# source .venv/bin/activate        # Linux / macOS

pip install -r requirements.txt
```

**4. Миграции и системные категории**

```bash
alembic upgrade head
python -m app.db.seed
```

**5. Старт**

```bash
uvicorn app.main:app --reload
```

В логах:

```
✓ категорияҳо: 10 нав, 10 ҳамагӣ
INFO  [amiri] Бот дар реҷаи polling
Run polling for bot @your_bot
```

- Проверка: http://localhost:8000/health
- Документация API: http://localhost:8000/docs

> ⚠️ **Один токен — один запущенный бот.** Telegram не отдаёт обновления
> двум процессам сразу (ошибка 409). Если бот уже где-то запущен, остановите
> его перед стартом.

`.env` читается по абсолютному пути от `app/config.py`, поэтому запускать
можно из любой папки.

## Переменные окружения

Шаблон — `.env.example`. Файл `.env` в git **не попадает**.

| Переменная | Обязательна | По умолчанию | Зачем |
|---|---|---|---|
| `BOT_TOKEN` | **да** | — | Токен от [@BotFather](https://t.me/BotFather) |
| `OPENAI_API_KEY` | **да** | — | Ключ OpenAI |
| `OPENAI_MODEL` | нет | `gpt-4o-mini` | Модель для категорий, свободного текста и чеков |
| `DATABASE_URL` | **да** | `...@localhost:5432/amiri` | Адрес PostgreSQL, драйвер `asyncpg` |
| `JWT_SECRET` | **да** | `change-me` | Подпись сессии панели, 64 символа |
| `JWT_TTL_DAYS` | нет | `7` | Сколько живёт вход в панель |
| `MAGIC_TOKEN_TTL_MINUTES` | нет | `5` | Сколько живёт ссылка из `/panel` |
| `PANEL_URL` | нет | `http://localhost:5173` | Адрес панели: CORS, ссылка входа, Mini App |
| `BOT_MODE` | нет | `polling` | `polling` для разработки, `webhook` для сервера |
| `PUBLIC_URL` | для webhook | `http://localhost:8000` | Публичный адрес backend |
| `WEBHOOK_SECRET` | для webhook | `change-me` | Часть пути вебхука, случайная строка |
| `DEFAULT_LANG` | нет | `ru` | Язык, если Telegram не сообщил свой |
| `DEFAULT_CURRENCY` | нет | `TJS` | Базовая валюта нового пользователя |
| `DEFAULT_TZ` | нет | `Asia/Dushanbe` | Часовой пояс: от него зависят границы «сегодня» |
| `FX_API_URL` | нет | `open.er-api.com` | Источник курсов валют |

## API

Все роуты, кроме `/api/auth/*` и `/health`, требуют сессию.

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/auth/telegram-token` | Обмен одноразовой ссылки на сессию |
| `POST` | `/api/auth/miniapp` | Вход из Telegram Mini App по `initData` |
| `POST` | `/api/auth/logout` | Выход |
| `GET` `PATCH` | `/api/me` | Профиль, смена языка и валюты |
| `GET` | `/api/categories` | Системные + свои категории |
| `POST` `PATCH` `DELETE` | `/api/categories[/{id}]` | CRUD своих категорий |
| `GET` | `/api/expenses` | Список: `from`, `to`, `category_id`, `limit`, `offset`. Возвращает ещё сумму по фильтру |
| `POST` | `/api/expenses` | Добавить: `{"text": "кофе 350"}` или поля вручную. Всегда возвращает **список** — одно сообщение может быть несколькими расходами |
| `PATCH` `DELETE` | `/api/expenses/{id}` | Правка и удаление |
| `POST` | `/api/expenses/{id}/suggestion` | Ответ на предложенную AI категорию: `{"accept": true}` |
| `GET` `PUT` | `/api/limits` | Лимиты на месяц |
| `DELETE` | `/api/limits/{category_id}` | Снять лимит |
| `GET` | `/api/stats/summary` | Итог периода и сравнение с прошлым |
| `GET` | `/api/stats/by-category` | Для круговой диаграммы |
| `GET` | `/api/stats/by-day` | Для столбцов по дням |
| `GET` | `/api/export.csv` | Выгрузка |

Отчёты принимают либо `period=today\|week\|month`, либо произвольные
`from`/`to` в ISO — тогда период игнорируется.

## Как устроено

```
app/
├─ main.py           # FastAPI + бот в том же процессе
├─ config.py         # настройки из .env
├─ bot/
│  ├─ handlers/      # expense, photo, reports, limits, edit, callbacks, start
│  ├─ i18n/          # tg.py · ru.py · en.py — по ключу на строку
│  ├─ keyboards.py   # все inline-кнопки
│  └─ format.py      # деньги, диаграммы, карточки
├─ api/routes/       # auth, me, expenses, categories, limits, stats, export
├─ db/               # models, session, seed
└─ services/
   ├─ parser.py      # «кофе 350» → сумма, валюта, описание
   ├─ ai.py          # категория, свободный текст, чек
   ├─ intake.py      # одна дверь: правило → AI
   ├─ categorizer.py # 5 шагов поиска категории
   ├─ fx.py          # курсы, кэш по дням
   ├─ limits.py      # лимиты и пороги предупреждений
   └─ stats.py       # агрегаты для отчётов
```

**Почему бот и API вместе.** Общие модели, парсер и категоризатор. Разнести
их — значит держать две копии логики и ловить расхождения между ними.

**Поиск категории — пять шагов, от дешёвого к дорогому:**

1. Явный `#тег` или название категории словом
2. Память пользователя: поправили один раз — дальше мгновенно
3. Словарь ключевых слов на трёх языках
4. OpenAI со строгой схемой ответа
5. Если ничего не подошло — AI предлагает новую категорию, пользователь
   подтверждает кнопкой

`other` в список для AI **не передаётся**: иначе модель всегда сбегает туда
и новую категорию не предлагает никогда.

**AI не может потерять расход.** Таймаут, лимит, битый JSON — расход падает
в «Другое» и сохраняется. При ошибке квоты или ключа AI выключается на
30 минут, чтобы каждое сообщение не ждало впустую.

**Курс фиксируется при записи** — `fx_rate` и `amount_base` лежат в самой
строке расхода. Отчёт за прошлый месяц не меняется от сегодняшнего курса.
При смене основной валюты пересчитываются все расходы и лимиты сразу:
иначе итоги складывали бы рубли с сомони.

**Границы дня — по часовому поясу пользователя,** не по UTC. «Сегодня» для
Душанбе начинается в местную полночь.

## Тесты

```bash
pytest
```

| Файл | Что проверяет |
|---|---|
| `test_parser.py` | Суммы, валюты, `1к`, несколько расходов в сообщении, `#тег` |
| `test_i18n.py` | Все три языка имеют одни ключи и одни подстановки |
| `test_isolation.py` | **Данные пользователей не пересекаются** — чужой расход не виден, не читается, не правится, не удаляется |

Тесты ходят в ту же базу, но создают своих пользователей со случайным
`tg_id` и удаляют их за собой.

## Продакшен

```env
BOT_MODE=webhook
PUBLIC_URL=https://api.вашдомен
WEBHOOK_SECRET=<случайная строка>
PANEL_URL=https://вашдомен
```

При старте бот сам поставит вебхук на `PUBLIC_URL/webhook/<секрет>`.

Как только `PANEL_URL` станет HTTPS, включатся Mini App и кнопки-ссылки:
Telegram не принимает `localhost` в кнопках, поэтому на разработке они
заменяются обычным текстом.
